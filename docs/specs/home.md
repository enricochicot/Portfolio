## Tela HOME 

A tela HOME é a página inicial do portfólio, onde são apresentados os principais destaques e informações sobre o autor.

### Seções da Tela HOME

- **Cabeçalho:** Contém o nome do autor e a navegação principal.
- **Hero:** Apresenta nome, função, links para projetos e contato, além de uma foto do autor cercada pelas marcas das tecnologias do perfil.
- **Destaques:** Apresenta os principais projetos ou conquistas do autor.
- **Sobre:** Breve descrição sobre o autor.
- **Projetos:** Lista de projetos recentes com links para detalhes.
- **Contato:** Cartões para e-mail, localização e LinkedIn, links para redes sociais e formulário com nome, e-mail, assunto e mensagem. O envio abre o aplicativo de e-mail do visitante.
- **Rodapé:** Informações adicionais e links para redes sociais.

## Estilização

A tela HOME deve seguir a estilização do arquivo `home.css`.
