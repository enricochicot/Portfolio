# Páginas

Cada tela tem uma pasta própria com seu componente. As especificações em Markdown ficam fora do código, em `docs/screens/`:

- `Home/` e [`home.md`](../../docs/specs/home.md): tela inicial.
- `About/` e [`about.md`](../../docs/specs/about.md): tela sobre.
- `Projects/` e [`projects.md`](../../docs/specs/projects.md): tela de projetos.
- `Contact/` e [`contact.md`](../../docs/specs/contact.md): tela de contato.

A tabela de rotas, o comportamento de cada página e as regras de navegação estão documentados em [Arquitetura do Sistema](../../docs/SYSTEM_ARCHITECTURE.md).

Antes de alterar uma página, confira sua implementação e os dados compartilhados que ela consome.
